# 🚇 MetroMitra

MetroMitra is a modern **Android application** built using **Kotlin** and **Jetpack Compose**, designed to simplify metro travel for commuters.  
It provides **real-time metro route planning**, **fare estimation**, **station details**, and an intuitive, **Material Design UI**.

---

## 🧠 Tech Stack

- **Language:** Kotlin  
- **UI Toolkit:** Jetpack Compose  
- **Architecture:** MVVM (Model–View–ViewModel)  
- **Networking:** Retrofit / Ktor Client  
- **Dependency Injection:** Hilt / Koin  
- **Local Storage:** Room Database / DataStore  
- **Navigation:** Jetpack Navigation Component  
- **Asynchronous Tasks:** Kotlin Coroutines + Flow  
- **Maps & Location:** Google Maps API / Location Services  

---

## 🎯 Key Features

✅ **Live Metro Timings** – Get real-time train schedules and route updates  
✅ **Route Finder** – Suggests the fastest and cheapest route between stations  
✅ **Fare Calculator** – Automatically calculates travel fare based on distance  
✅ **Station Info** – View station facilities, exits, and nearby landmarks  
✅ **Favorites** – Save frequently used routes for quick access  
✅ **Offline Access** – View route maps and fare details even without internet  
✅ **Modern UI** – Built entirely with Jetpack Compose and Material3 Design
